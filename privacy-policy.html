Política de Privacidad de Hiraeth

Responsable del tratamiento: Hiraeth — proyecto desarrollado por Necel. Contacto: neceldev@gmail.com. Jurisdicción: República Argentina (Ley 25.326 de Protección de los Derechos de los Usuarios de Bancos de Datos).

Hiraeth es un bot de Discord gratuito. Esta política explica qué datos maneja el bot, qué datos guarda, con qué terceros se comparten, durante cuánto tiempo y qué derechos tienes bajo la ley argentina. No usamos cookies, ni analítica web, ni publicidad, ni vendemos datos.

1. Datos de identidad

El bot solo maneja identificadores de Discord: las "snowflakes" (identificadores numéricos) de usuario, servidor, canal y mensaje, junto con nombres de usuario y URL de avatares que muestra Discord. Nunca solicita ni almacena correo electrónico, teléfono, dirección IP, domicilio físico o nombre real.

Los identificadores de usuario de Discord son pseudónimos. Si un usuario escribe a neceldev@gmail.com (por ejemplo, para solicitar una supresión), su correo y el contenido de ese mensaje se guardan en el buzón del operador únicamente para gestionar la solicitud.

2. Acceso al contenido de los mensajes

El bot tiene habilitado el privilegio de Message Content de Discord. Procesa temporalmente los mensajes en los servidores donde está presente con los siguientes fines: conteo de XP, escaneo de automoderación (palabras prohibidas, invitaciones, flood), análisis del contador comunitario y el canal de chatbot con prefijo !.

Solo persiste lo que indica la tabla de la sección 3. No registra ni almacena el chat general.

3. Qué se almacena

La siguiente tabla refleja los datos guardados por cada modelo de MongoDB del bot:

Función Dato almacenado Retención
Chatbot IA (conversaciones) Texto literal del mensaje que el usuario envía con prefijo ! en canales de chatbot, y las respuestas del modelo. Hasta 20 turnos de historial por usuario por servidor. El historial está acotado estrictamente por {servidor, usuario}; los historiales de distintos usuarios y distintos servidores nunca se mezclan. Eliminación automática 30 días tras inactividad (TTL).
XP y niveles ID de usuario, ID de servidor, cantidad de XP, nivel y marca de tiempo del último XP. No se almacena contenido de mensajes. Indefinida.
Economía virtual ID de usuario global (no por servidor), saldo de monedas, totales ganados/gastados, inventario de objetos y marcas de tiempo de reclamo diario/trabajo. Indefinida.
Cumpleaños ID de usuario, ID de servidor, día, mes y año opcional (el año permite derivar la edad). Eliminado vía /birthday delete (usuario) o /birthday delete-user (admin); si no, indefinida.
Advertencias (moderación) ID de usuario, ID de servidor, motivo de texto libre escrito por moderadores o auto-generado por automod (los motivos de automod incluyen la única palabra prohibida coincidente — nunca el mensaje completo), fecha. Decaimiento configurable por servidor (warningDecayDays); si está deshabilitado, indefinida.
Encuestas ID del autor, texto libre de pregunta y opciones, y qué ID de usuario votó qué. Las encuestas cerradas se auto-eliminan 7 días después (TTL).
Recordatorios ID de usuario, ID de servidor/canal, texto de recordatorio escrito por el usuario (máx. 500 caracteres). Eliminado inmediatamente tras la entrega (TTL ~5 min tras la hora programada). Se entrega por DM o, si falla, en el canal.
Tareas personales (to-do) ID de usuario + contenido de tarea de texto libre. Matiz que divulgamos con honestidad: las tareas son de ámbito de usuario a través de TODOS los servidores (creadas en un servidor, visibles en otro). No hay borrado masivo accesible al usuario más allá de la eliminación por tarea en la interfaz; si no, indefinida.
Contador comunitario ID de usuario, el número contado y marca de tiempo de cada conteo (historial indefinido); los contadores de fallo por usuario se auto-eliminan tras 90 días. Historial indefinido; contadores de fallo: auto-eliminación a los 90 días.
Noches de cine (película) Título/fecha/hora/sinopsis de trama (texto libre, autor del usuario), tag de Discord del proponente, URL de avatar e ID, IDs de votantes y puntuaciones. Indefinida.
Partidas de juegos (Wordle/Battleship/Sea of Words/Tres en línea/Buscaminas/Mecanografía) IDs de usuario, estadísticas numéricas y estado de sesión activa (datos de tablero/intento). Las sesiones caducan automáticamente y se limpian al reiniciar. No hay contenido de mensajes. Mientras dura la sesión; estadísticas indefinidas.
Acciones moderadas programadas (ban/mute temporales) ID de usuario, ID de moderador, motivo de texto libre (máx. 512), marcas de tiempo de ejecución. Eliminado en cuanto se ejecuta.
Configuración del servidor (creada por admin) IDs de canal/rol, ajustes de automod incl. lista de palabras prohibidas, plantillas de mensajes de bienvenida/salida, texto de persona del chatbot, recompensas de subida de nivel. Creado/eliminado por administradores del servidor. Indefinida mientras esté configurada.
Base de conocimiento del servidor (Q&A de admin, máx. 50 entradas/servidor) Preguntas y respuestas almacenadas indefinidamente hasta eliminarse con /knowledge remove. Se envían al proveedor de IA como contexto. Indefinida hasta su eliminación.
Mensajes anónimos (/anonimo) El mensaje se publica sin autor visible en el canal, pero el tag y el ID del autor se registran en un canal de registro del servidor visible para los moderadores. Mientras el canal de registro lo retenga (hasta que el servidor lo elimine).

4. Terceros

Flujos exactos de datos con terceros:

  • Google Gemini (Google LLC): recibe el texto del mensaje del chatbot (≤1500 caracteres), hasta 20 turnos previos, el texto de persona configurado por el admin del servidor y hasta 3 entradas de conocimiento Q&A del admin que coincidan. No recibe IDs de usuario de Discord, IDs de servidor, nombres de usuario ni avatares. El procesamiento puede ocurrir en servidores fuera de Argentina (transferencia internacional).
  • WeatherAPI: solo el nombre de la ciudad que escribió el usuario (comando de clima).
  • YouTube Data API v3 (Google): solo el término de búsqueda escrito por el usuario.
  • dolarapi.com: ningún dato de usuario (cotizaciones públicas).
  • Discord (Discord Inc.): plataforma que aloja inherentemente todos los IDs/contenidos.
  • Base de datos: MongoDB utilizada por el bot; el acceso está restringido al operador. Sin cookies, sin analítica web, sin publicidad, sin venta de datos.

Ninguna clave de API se expone nunca a los usuarios.

5. Resumen de retención

Los TTL automáticos figuran en la tabla anterior. XP, economía, estadísticas de juegos, historial del contador, cumpleaños, datos de películas y configuración/conocimiento del servidor persisten de forma indefinida hasta que se eliminan mediante los mecanismos listados o por solicitud de supresión.

Los datos no se borran automáticamente cuando un usuario sale de un servidor ni cuando el bot se retira de un servidor. Las solicitudes de supresión son el medio por el cual los usuarios cierran esa brecha. Lo señalamos con honestidad.

6. Tus derechos (Ley argentina 25.326)

Conforme a la Ley 25.326:

  • Art. 14 — derecho de acceso, rectificación, actualización y supresión de datos (habeas data).
  • Art. 16 — la gestión de datos de menores requiere la intervención de su representante legal bajo la ley argentina.
  • Derecho a presentar una denuncia ante la Agencia de Acceso a la Información Pública (AAIP).

Cómo ejercerlos

Escribe a neceldev@gmail.com incluyendo tu ID de usuario de Discord (activa el Modo Desarrollador → clic derecho en ti → Copiar ID) y, para datos por servidor, el nombre del servidor. El operador puede pedir confirmar razonablemente que la solicitud proviene del dueño de la cuenta. Tiempo de respuesta objetivo: dentro de los 30 días.

Existen comandos de auto-servicio para:

  • Cumpleaños: /birthday delete
  • Recordatorios: /remind cancel
  • Tareas: eliminación por tarea
  • Administradores de servidor: pueden eliminar las advertencias de su servidor (/warns remove), entradas de conocimiento y configuración.

Los registros de moderación vinculados a la administración del servidor son responsabilidad de los administradores de ese servidor; los usuarios deben contactar al personal del servidor para esos casos (el desarrollador no adjudica moderaciones).

7. Postura de seguridad

El acceso a la base de datos está restringido al operador. Las llamadas externas usan HTTPS. Ninguna clave secreta se expone a los usuarios. No hacemos afirmaciones adicionales más allá de estas medidas.

Hiraeth Privacy Policy

Data controller: Hiraeth — a project developed by Necel. Contact: neceldev@gmail.com. Jurisdiction: Argentine Republic (Law 25.326 on the Protection of the Rights of Database Users).

Hiraeth is a free Discord bot. This policy explains what data the bot handles, what data it stores, which third parties it shares data with, for how long, and what rights you have under Argentine law. We do not use cookies, web analytics, advertising, or sell data.

1. Identity data

The bot only handles Discord identifiers: user, guild, channel, and message ID snowflakes, along with usernames and avatar URLs shown by Discord. It never asks for or stores email, phone number, IP address, physical address, or real names.

Discord user IDs are pseudonymous. If a user writes to neceldev@gmail.com (for example, to request deletion), their email and the message content are stored in the operator's mailbox solely to handle the request.

2. Message content intent

The bot has Discord's Message Content privilege enabled. It temporarily processes messages in servers it is in for: XP counting, automod scanning (banned words, invites, flood), community counter parsing, and the !-prefixed chatbot channel.

It only persists what the table in section 3 lists. It does not log or store general chat.

3. What is stored

The following table reflects the data stored by each of the bot's MongoDB models:

Function Stored data Retention
AI Chatbot (conversations) Verbatim message text the user sends with the ! prefix in chatbot channels, plus model responses. Up to 20 turns of history per user per server. History is scoped strictly per {server, user}; histories of different users and different servers never mix. Auto-deleted 30 days after inactivity (TTL).
XP and levels User ID, guild ID, XP amount, level, and last-XP timestamp. No message content stored. Indefinite.
Virtual economy Global user ID (not per-guild), coin balance, totals earned/spent, item inventory, and daily/work claim timestamps. Indefinite.
Birthdays User ID, guild ID, day, month, and optional year (the year enables age derivation). Deleted via /birthday delete (user) or /birthday delete-user (admin); otherwise indefinite.
Warnings (moderation) User ID, guild ID, free-text reason written by moderators or auto-generated by automod (automod reasons include the single banned word matched — never the full message), date. Per-guild configurable decay (warningDecayDays); if disabled, indefinite.
Polls Author ID, question and option free text, and which user ID voted what. Closed polls auto-delete 7 days later (TTL).
Reminders User ID, guild/channel IDs, user-written reminder text (max 500 chars). Deleted immediately after delivery (TTL ~5 min after scheduled time). Delivered via DM or channel fallback.
Personal tasks (to-do) User ID + free-text task content. Honest disclosure nuance: tasks are user-scoped across ALL servers (created in one server, visible in another). There is no user-facing bulk delete beyond per-task UI deletion; otherwise indefinite.
Community counter User ID, the number counted and timestamp of each count (indefinite history); failure counters per user auto-delete after 90 days. Indefinite history; failure counters: auto-delete after 90 days.
Movie nights (film) Proposal title/date/time/plot synopsis (free text, user-authored), proposer's Discord tag, avatar URL and ID, voter IDs and scores. Indefinite.
Game sessions (Wordle/Battleship/Sea of Words/Tic-Tac-Toe/Minesweeper/Typing) User IDs, numeric stats, and active session state (board/guess data). Sessions auto-expire and are cleaned on restart. No message content. While the session lasts; stats indefinite.
Scheduled moderation actions (temp ban/mute) User ID, moderator ID, free-text reason (max 512), execution timestamps. Deleted as soon as executed.
Server configuration (admin-authored) Channel/role IDs, automod settings incl. banned-word list, welcome/leave message templates, chatbot persona text, level-up rewards. Created/removed by server admins. Indefinite while configured.
Server knowledge base (admin Q&A, max 50 entries/guild) Stored indefinitely until removed with /knowledge remove. Sent to the AI provider as context. Indefinite until removal.
Anonymous messages (/anonimo) The message is posted without a visible author in the channel, but the author's tag and ID are logged to a server log channel visible to moderators. While the log channel retains it (until the server removes it).

4. Third parties

Exact data flows with third parties:

  • Google Gemini (Google LLC): receives the chatbot message text (≤1500 chars), up to 20 previous turns, the server's admin-configured persona text, and up to 3 matching admin Q&A knowledge entries. It does not receive Discord user IDs, guild IDs, usernames, or avatars. Processing may occur on servers outside Argentina (international transfer).
  • WeatherAPI: only the city name the user typed (weather lookup command).
  • YouTube Data API v3 (Google): only the search term typed by the user.
  • dolarapi.com: no user data at all (public rates).
  • Discord (Discord Inc.): the platform inherently hosting all IDs/content.
  • Database: MongoDB used by the bot; access restricted to the operator. No cookies, no web analytics, no advertising, no selling of data.

No API keys are ever exposed to users.

5. Retention summary

Automated TTLs are listed in the table above. XP, economy, game stats, counter history, birthdays, movie data, and guild config/knowledge persist indefinitely until removed via the listed mechanisms or by a deletion request.

Data is not automatically erased when a user leaves a server or when the bot is removed from a guild. Deletion requests are how users close that gap. We state this honestly.

6. Your rights (Argentine Law 25.326)

Under Law 25.326:

  • Art. 14 — right of access, rectification, update, and suppression of data (habeas data).
  • Art. 16 — handling of minors' data requires legal-representative involvement under Argentine law.
  • Right to file with the Agencia de Acceso a la Información Pública (AAIP).

How to exercise them

Email neceldev@gmail.com including your Discord user ID (enable Developer Mode → right-click yourself → Copy ID) and, for server-scoped data, the guild name. The operator may ask to reasonably confirm the request comes from the account owner. Target response time: within 30 days.

Self-service commands exist for:

  • Birthdays: /birthday delete
  • Reminders: /remind cancel
  • Tasks: per-task delete
  • Server admins: can remove their server's warnings (/warns remove), knowledge entries, and config.

Moderation records tied to server administration remain the server admins' responsibility; users should contact server staff for those (the developer does not adjudicate moderation).

7. Security posture

Database access is restricted to the operator. External calls use HTTPS. No secret keys are exposed to users. We make no claims beyond these measures.
